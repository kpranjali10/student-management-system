# Student Management System

This is my first project, named **Student Management System**.

It is based on Python basics and covers topics such as:

* Functions
* Loops
* Dictionaries
* Strings
* If-else statements

## Features

1. Add student data :
   * Name
   * Roll number
   * Subject
   * Marks

2. Search for a student

3. Calculate student's percentage

4. Find the class topper

5. Delete a student and their data

This project was my first step toward learning Python and implementing what I learned along the way.
